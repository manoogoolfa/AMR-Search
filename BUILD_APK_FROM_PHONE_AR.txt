بناء AMR Search APK من الموبايل فقط

1) أنشئ حسابًا مجانيًا على GitHub من المتصفح.
2) أنشئ مستودعًا جديدًا (New repository)، واجعله Private، ثم Create repository.
3) ارفع محتويات مجلد AMR_Android إلى المستودع. يجب أن يكون مجلد app وملف build.gradle.kts وملف settings.gradle.kts في جذر المستودع، وكذلك مجلد .github.
   ملاحظة: إذا لم يظهر مجلد .github في منتقي الملفات، ارفع المشروع من خلال واجهة GitHub على المتصفح مع إظهار الملفات المخفية، أو أنشئ الملف يدويًا بالمسار .github/workflows/build-apk.yml وانسخ محتواه من المشروع.
4) افتح تبويب Actions في المستودع.
5) اختر Build AMR Search APK ثم Run workflow ثم Run workflow.
6) انتظر حتى تنتهي المهمة بنجاح.
7) افتح تشغيل المهمة الناجح، وانزل إلى Artifacts، ثم نزّل AMR-Search-APK.zip.
8) افتح الملف المضغوط واستخرج app-debug.apk، ثم اضغط عليه وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

مهم: ملف APK الناتج هنا نسخة Debug للتجربة. لا تشاركها كتطبيق موثوق أو تنشرها تجاريًا قبل مراجعة الأمان وإعداد توقيع إصدار Release.
