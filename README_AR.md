# AMR Search — تطبيق أندرويد

هذا مشروع Android Studio لتطبيق أندرويد باسم **AMR Search**. التطبيق يفتح واجهة محرك البحث من خادمك عبر HTTPS، ويحفظ رابط الخادم على الجهاز.

## مهم قبل تثبيت التطبيق
ملف APK النهائي غير مرفق في هذه الحزمة؛ بيئة الإنشاء الحالية لا تحتوي على Android SDK أو Gradle. هذه ملفات المصدر الجاهزة للبناء في Android Studio.

كذلك يجب نشر المحرك الخلفي الموجود في مجلد `backend` على خادم HTTPS عام أولًا. بعد النشر، افتح التطبيق وأدخل رابط الخادم، مثل:
`https://amr.example.com`

## بناء APK باستخدام Android Studio
1. ثبّت Android Studio على كمبيوتر.
2. افتح مجلد `AMR_Android` كمشروع.
3. انتظر Gradle Sync، وثبّت Android SDK 35 إذا طلبه البرنامج.
4. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. ستجد APK عادةً في:
   `app/build/outputs/apk/debug/app-debug.apk`

## نشر المحرك الخلفي
مجلد `backend` يحتوي نسخة محرك البحث Python. راجع `backend/README.md` لتشغيله. للنشر العام استخدم استضافة تدعم Python وHTTPS، ولا تضع الخادم مكشوفًا قبل إضافة المصادقة وحدود الاستخدام وقائمة النطاقات المسموح بفحصها.

## ما يقدمه التطبيق
- اسم التطبيق: AMR Search
- واجهة Android WebView لواجهة محرك البحث.
- حفظ رابط الخادم.
- زر لتغيير الخادم.
- فتح الروابط الخارجية في المتصفح.
- يتطلب اتصال إنترنت وخادم AMR يعمل.

## ملاحظات أمان
لا تدخل عنوان خادم غير موثوق. لا تستخدم المحرك إلا على مواقع لديك تصريح بفحصها. يجب تقوية واجهة الخادم قبل إتاحتها للعامة.
