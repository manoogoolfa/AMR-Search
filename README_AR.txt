AMR Search — مشروع أندرويد أولي

هذه حزمة مشروع Android Studio (ملفات المصدر)، وليست APK جاهزًا للتثبيت.

طريقة بناء APK:
1) ثبّت Android Studio حديثًا وافتح مجلد AMR_Android.
2) انتظر Gradle Sync، وثبّت Android SDK Platform 35 إذا طُلب.
3) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4) ستجد الملف غالبًا في app/build/outputs/apk/debug/app-debug.apk.

المميزات الحالية:
- واجهة أندرويد عربية باسم AMR Search.
- بحث عبارة نصية داخل صفحات HTML العامة ضمن المواقع التي تدخلها.
- زحف محدود للروابط الداخلية (حتى 50 صفحة لكل موقع في الجولة).
- احترام robots.txt ومحاولة منع عناوين الشبكات الخاصة والتحويلات إليها.
- متابعة دورية عبر WorkManager وإشعار عند العثور على نتائج.
- لا يحتاج إلى خادم CyberSearch الخارجي.

حدود النسخة:
- هذه نسخة أولية للتجربة، ولا تحفظ سجل النتائج بعد إغلاق التطبيق.
- لا تبحث في محتوى PDF/Word أو الصفحات التي تُنشأ بالكامل بجافاسكربت.
- جدولة Android دورية تقريبية وقد يؤخرها نظام توفير البطارية.
- فحص المواقع يتطلب إذنًا، ولا يتجاوز تسجيل الدخول أو CAPTCHA أو الحماية.
- قبل النشر العام يلزم إضافة تخزين دائم، إدارة نتائج ومقارنة تغيّر المحتوى، حدود طلبات أقوى، واختبارات أمنية واختبارات توافق.
